# F1 Mini World for iPad

三個獨立 Scriptable 小工具。資料由 iPad 直接取得，安裝後不需要電腦保持開機。

## 本版狀態

2026.11.25.2 為可測試開發版。整體估計 38%，按賽道 50%、計時 20%、維修區 15%、安裝可靠性 15% 加權取整。

| 模組 | 估計完成度 | 已完成與缺口 |
| --- | --- | --- |
| 賽道 | 32% | 24 條參考路線、獨立圖片區、橫向版、日夜配色、當地時間、天氣、跨年賽程與離線備援。經實景核對的完整微縮城市模型仍為 0 站 |
| 計時 | 40% | 歷史排位／衝刺／正賽分類、車隊色、圈數、差距、全表與快取。免費即時計時尚未實現 |
| 維修區 | 42% | 新版 AI 微縮場景、四階段圖像播放、暫停／重播／逐步操作、素材驗證及離線快取。新版 iPad 顯示與視覺驗收待確認 |
| 安裝與可靠性 | 50% | 固定提交、SHA-256 驗證、重複安裝檢查、失敗清理、30 項本機回歸測試。新版 iPad 安裝待驗證 |

舊版方形路線已由使用者在 iPad 確認顯示。新版賽道排版、賽果全表及舊版維修區介面已由使用者確認可開啟。使用者要求改善維修區質感，因此新增詳細的四階段場景素材。測試使用合成資料，僅存在 tests 目錄，正式腳本不帶測試賽果。

## 一次安裝

1. 在 Scriptable 新增腳本，貼上本專案的 install-release.js 並執行。
2. 安裝器先下載及驗證三個腳本，再建立帶版本碼的新腳本。
3. 回到 Scriptable 清單，可看到「F1 賽道」、「F1 賽果」、「F1 維修區」。先開啟新版 F1 維修區一次，下載並驗證約 2.75 MB 的場景素材。
4. 在 iPad 主畫面加入 Scriptable 大型或超大型小工具，在 Script 選擇對應版本腳本。
5. 點擊賽果可看全表，點擊維修區可播放動畫。

超大型小工具自動選橫向版。Scriptable 編輯器直接執行時通常預覽大型版。可以在小工具 Parameter 填入以下選項。

| 腳本 | Parameter | 效果 |
| --- | --- | --- |
| 賽道 | 留空 | 依小工具尺寸顯示 |
| 賽道 | wide | 橫向版 |
| 賽果 | 留空 | 最近可取得的競賽場次歷史賽果 |
| 賽果 | race | 正賽 |
| 賽果 | qualifying | 排位賽 |
| 賽果 | sprint | 衝刺賽 |
| 賽果 | sprint-qualifying | 衝刺排位 |
| 賽果 | wide race | 橫向正賽表 |
| 維修區 | preview | 直接執行時預覽靜態桌面版本 |
| 維修區 | wide preview | 橫向靜態預覽 |

每次更新可執行新版安裝器，再於小工具選取新版本腳本。安裝器使用不可變提交，既有版本不會自動下載新程式碼。賽程與天氣仍會在執行時更新。

原本直接載入 main/mini-world.js 的程式仍可使用，但 main 連結可能受到傳輸快取影響，且原載入器沒有檔案雜湊驗證。推薦使用本版安裝器。安裝器本身應由你信任的專案來源取得，檔案雜湊無法代替對安裝器來源的信任。

## 資料與實際限制

- Jolpica 提供年度賽程和備援正賽結果。程式優先找尚未結束的當季大獎賽，季末查下一年。新賽程尚未公布時保留上站並標示待公布。
- 自動換站以預定正賽開始後四小時作為選站界線。延賽、長時間紅旗或取消的情況，尚未接入即時賽事狀態判斷。
- Open-Meteo 提供賽道座標天氣及 IANA 時區。時間在小工具重新執行時更新。桌面更新時機由 iPadOS 決定，15 分鐘是更新請求。
- OpenF1 官方文件列出免費歷史資料與付費即時資料。本版僅使用免費歷史端點。顯示「歷史賽果」或「快取」，不會宣稱為即時。
- 最新場次結果缺失時，最多嘗試最近三個符合類型的已結束場次。預設與正賽模式另有 Jolpica 備援。
- 車隊顏色由資料源回傳。色碼缺失時使用中性色，避免錯誤指定車隊顏色。
- 排位賽的 Q1／Q2／Q3 差距依各車手最後有成績的階段顯示，對應該階段領先時間。
- 快取只在成功取得有效資料後保存。第一次離線啟動會顯示資料無法取得。
- 維修區使用 AI 生成的通用微縮場景，包含四張分階段插畫。桌面顯示一個完整階段，點擊後每 2.5 秒切換，可暫停、重播及指定階段。圖中車隊與車庫屬藝術設計，未對應特定真實車隊。
- 新素材已實際下載核對 SHA-256，並以原始圖片及等比例取景檢查畫面。30 項回歸測試中包含 7 個新版維修區檢查。新版 iPad 視覺驗收仍待確認。

## 微縮素材擴充

assets/manifest.json 使用 version 2。circuits 目前為空。新增素材須包含以下欄位並完成實景核對。

- verified 設為 true
- seasons 填入已核對的數字年份陣列
- sources 列出布局、建築及地形來源
- scenes 依 day-clear、night-clear、day-cloud、night-rain 等天氣時段索引
- 每個場景提供 square 與 wide 的 assets/ 內 PNG 或 JPEG 路徑

程式只使用符合當季、具有來源且已核對的素材。缺少符合天氣與時段的素材時顯示參考路線或待更新。完整賽道必須位於素材範圍內，程式使用等比例完整顯示。

## 測試

需要 Node.js 22 或更新版本。

```sh
node tests/regression.cjs
```

30 項測試涵蓋跨年、離線、損壞快取、舊版快取、路線完整邊界、排位成績、缺失賽果、HTML 跳脫、動畫控制、SHA-256、安裝防竄改、失敗清理與重複安裝。

測試以 Scriptable API 的替身執行正式入口程式。實際 iPad 字體、版面大小、iCloud 同步、Widget 記憶體上限與更新排程仍需實機測試。

## iPad 本輪一次驗收

1. 執行安裝器，確認三個版本腳本建立成功。
2. 執行賽道腳本，確認路線與文字分開。
3. 加入超大型賽道小工具，確認完整路線與右側資訊。
4. 執行賽果腳本，確認資料來源、歷史標示與全部車手表。
5. 執行維修區，測暫停、重播、下一階段。
6. 加入維修區桌面小工具，點擊確認會開啟動畫。
7. 成功載入資料後關閉網路，再測三個已安裝腳本。
